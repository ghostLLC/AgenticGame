# 本机数据规模测量

使用 `npx tsx scripts/acceptance/data-scale.ts`，在同一台 Windows 开发机、Node 22.16 上运行。夹具包含 100 / 1000 份完整校验的真实 120 回合比赛回放及 500 个连续、校验有效的战术版本。两次测量复用完全相同的数据，不包括截图渲染或安装包启动。

| 操作 | 改动前 | 改动后 |
| --- | ---: | ---: |
| 100 场首次完整校验 | 352 ms | 376 ms |
| 100 场再次校验列表 | 355 ms | 4 ms |
| 100 场回放列表刷新 | 986 ms | 8 ms |
| 1000 场首次完整校验 | 3701 ms | 3568 ms |
| 1000 场再次校验列表 | 3465 ms | 34 ms |
| 1000 场回放列表刷新 | 9871 ms | 50 ms |
| 500 版本 + 1000 回放的车库读取 | 7353 ms | 360 ms |
| 最后一个测量点进程 RSS | 257 MiB | 137 MiB |

列表刷新与车库读取发生在首次校验之后，因此是进程内缓存已建立时的数据。首次进入拥有 1000 场回放的档案，仍需要约 3.6 秒完整校验。这是两次本机测量，不是跨设备性能承诺；RSS 是测量点采样，不是进程峰值。

实现保留最多 2000 条已验证摘要，按文件大小、修改时间、状态变更时间和文件编号使缓存失效；摘要不写到磁盘。删除与损坏条目会从缓存移除，打开、分享或备份具体回放时仍执行完整校验。读取并发最多 4 份完整回放，说明文件最多并发 8 份。列表默认每页 40 场、单次最多 100 场；车库历史首次渲染 40 个版本，可按需继续加载。

原始测量位于本机忽略目录 `.tmp/data-scale-quality/measurement-1788607819270.json` 和 `measurement-1788610578894.json`；脚本可从空目录重建夹具。测试数据及私有回放不随仓库上传。
