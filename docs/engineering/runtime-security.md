# 0.1.1 策略执行与数据边界

适用：本地 Public Beta B 修复候选，2026-09-05。范围不包括公开排位服务。

## 策略执行

- 固定 QuickJS 0.32.0 WASM 解释器，在独立 Node/Electron 子进程中运行。宿主与策略只交换序列化数据；不向策略导出宿主函数或对象。
- 策略源码最多 256 KiB；上下文/视图最多 1 MiB；动作输出最多 16 KiB。
- 解释器堆 32 MiB、栈 512 KiB；WASM 线性内存 16 MiB 初始、64 MiB 上限。Node 旧生代配置 128 MiB，这是 V8 堆限制，不等于总 RSS 上限。
- 每回合最多 5 条日志、全场最多 300 条，每条最多 1,024 字符。禁止真实时间，禁用 Math.random，使用确定性 rng。
- 父进程执行初始化/回合期限和整场一分钟期限；超时、致命执行错误或取消会终止子进程。AI 任务四分钟、一次一个，候选缓存最多 8 个。
- 回合的解释器预算按独立进程 CPU 用时计量，桌面 Gameplay v2 默认 100ms（legacy v1 仍为 30ms），调用预算限制为 1–1,000ms；CPU 用时由 QuickJS 中断回调采样检查。Windows 调度暂停不直接计入执行消耗，解释器单调墙钟和父进程额外 500ms 的等待上限仍独立生效，总等待最多 1,500ms。此预算包含解释器开销，不是跨硬件相同指令数的燃料模型。
- 子进程环境只保留 Windows 运行所需的系统/临时目录变量，不继承 API Key、NODE_OPTIONS 等宿主配置。
- ASAR 中的 worker 会复制到本机私有临时目录，使用随机目录、退出清理；可打包 Bridge 自身以内部参数启动策略子进程。

没有 Windows Restricted Token、AppContainer、Job Object 总内存/子孙进程策略，也没有经独立安全评估证明 WASM/解释器不存在漏洞。进程与解释器边界不等于 OS 沙箱；公开对抗性执行前仍需操作系统隔离和攻击面复核。

## IPC 与网络

- Electron contextIsolation 开启、nodeIntegration 关闭，preload 提供固定方法；主进程验证自有窗口、确切主 frame 和确切本地 renderer URL。
- 禁止任意页面导航、webview 与浏览器权限；外链仅允许本项目 GitHub 的明确页面范围。
- Provider HTTP 响应边读边限流，超限取消，支持 AbortSignal 和请求期限；错误消息脱敏。
- DataChannel 分帧限制帧数、单帧长度、整条消息、并发未完成消息、累计内存、过期时间与待发缓冲；重复冲突帧拒绝，关闭时清理。
- 好友赛基于互信、房主权威；房主会收到客人的完整源码。公开回放的脱敏不改变这一点。

## 持久化与隐私

- Build、注释、回放和配置使用内核互斥配合写入锁、临时文件同步和原子替换；进程退出后内核释放互斥。未知同次开机旧锁不盲目抢占，提示关闭旧版并重启电脑。
- Build 保存比较预期最新版本；冲突拒绝且保留草稿。说明先成功保存，版本才发布；重复内容可单独修改说明。
- 隔离损坏版本、回收站搬移/恢复具有持久化续接记录。目标冲突或路径异常时保留所有可恢复文件；健康记录仍可读取。仅已正常提交的回收站条目参与七天清理。
- 回放摘要内存缓存最多 2,000 条，以文件身份/修改元数据失效；真正打开、导出和加载时始终完整校验。它是性能索引，不能作为敌对本机文件系统的独立可信根。
- API Key 仅在当前任务内存使用。私有评测证据保存完整策略及指标，不含密钥和目标对话；默认界面仅展示摘要与证据文件名。
- 默认公开导出省略源码、动作与日志；完整备份明确标注含代码。导入文件上限 16 MiB，校验包结构及完整性。
- Host 配置写入前备份、检测并发修改、写后回读。与不遵守本应用互斥协议的外部编辑器之间仍存在检查到原子替换的短暂竞争窗口，不能承诺 OS compare-and-swap。

验证来自 bot-isolation、resource-bounds、renderer-security、write-lease、仓库恢复与 IPC 回归，以及最终桌面/Bridge EXE 的真实执行。真实第三方 Host 接入、付费模型调用与双设备网络验收仍独立记录。
