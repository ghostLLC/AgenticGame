2026-09-05，基于 `93c2002`，分支 `codex/quality-repair-20260905`。用户授权全面审查后的修复及 Ardot、飞书、README、GitHub 同步。

## 启动故障

0.1.0 把 jsonc-parser 的 UMD 模块打入主进程后，运行时相对 require 丢失原有目录，安装版报 `Cannot find module './impl/format'`。0.1.1 将该模块作为完整生产依赖随 ASAR 分发，并增加最终 EXE 运行检查。仅 TypeScript 编译通过不足以覆盖这类故障。

新候选已从最终目录版 EXE 和 NSIS 解出的实际负载启动；两者均完成真实主进程、preload、renderer 的可信 IPC 初始化和包内教学战斗，生成 23 帧回放。最终目录版 Agent Bridge 完成六工具发现、两次保存和一场据点赛回读。此证据不等于执行过 NSIS 安装/升级/卸载向导。

## 验证与边界

- 全量测试：66 个文件、306 项通过；TypeScript 类型检查、通用与桌面构建通过，依赖审计 0 漏洞。
- 集成分页测试包括两个真实子进程比赛和落盘，预算调整为 15 秒，以适应全套测试争用；这不是列表交互延迟承诺。
- 1,000 场回放热列表约 50ms；500 版本 + 1,000 场回放的车库约 360ms；首次冷校验约 3.6s。[口径与原始测量](../engineering/2026-09-05-performance.md)。
- GUI 验收使用本机 Windows 的独立测试资料。键盘回放、教学/镜像赛与模态焦点有真实操作证据；不等价于新手可用性研究。
- NSIS 负载与目录版的 ASAR/Bridge 哈希已比对；还需在清洁 Windows 环境执行安装、覆盖升级、卸载和资料保留检查。
- 未签名。没有已授权或提供的受信任 CA 证书；不会以自签名或完整性哈希代替可信签名。
- 真正双设备局域网/异地邀请/重启恢复、真实 Host 配置接入、付费 AI 厂商及新手研究尚待外部验收。没有部署 TURN、服务器、排位或商业化 C 功能。
