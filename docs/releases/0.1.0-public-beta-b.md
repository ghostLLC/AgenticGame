# AgenticGame 0.1.0 Public Beta B

候选刷新日期：2026-09-04

## 这次可以做什么

- 不需要命令行即可完成首次教学、保存多个战术版本、新旧版本练习、查看完整回放和复盘笔记。
- 好友房间支持同一局域网自动发现与异地手动邀请。战术在连接后由游戏自动同步，不需要双方传文件。
- 房间意外断开或应用重启后，可在 24 小时内通过 Windows 系统加密信息重新会合。
- AI 战术教练支持 OpenAI-compatible 与 Anthropic 原生接口。密钥只用于本次运行，不写入档案、战报或诊断；AI 候选经过 3/5/10 场真实沙盒评测后，只有玩家确认才保存为新版本。
- Codex、WorkBuddy、Qoder 等外部 Agent 可通过发行包自带的 `AgenticGame-Agent.exe` 直接读取游戏规则和玩家版本、真实评测并保存新版本、发起新旧版本练习赛和读取战绩；无需 Node、项目源码、网络端口或手工传文件。
- 游戏内新增 Codex、WorkBuddy、Qoder 一键接入：只在玩家点击后合并 AgenticGame 连接，保留其他配置并为既有文件创建恢复备份；完成后重启对应 AI 工具即可使用。
- Windows 单文件构建不再产生无效模块 URL 警告；发布回归会实际启动两个单文件程序读取内置地图和接入配置，防止只消除日志而破坏资源定位。
- Windows 安装包元数据使用公开的 `ghostLLC/AgenticGame` 维护主体与项目主页；构建只关闭证书签名而保留可执行文件资源编辑，实测 EXE 的 ProductName、CompanyName 与 ProductVersion 已写入。这不代表二进制已经取得代码签名。
- 整备中心提供音量、动效、好友偏好、七项运行检查、脱敏诊断导出和旧版战术/回放导入。

## 联机边界

AgenticGame 没有项目自有服务器，也没有中继服务器。局域网发现使用临时本地广播，比赛数据通过玩家之间的 WebRTC DataChannel 传输；异地连接依赖公网 STUN 与双方 NAT 条件。严格 NAT、企业网或运营商网络可能无法异地直连，游戏会提供检查结论，但不会伪装成连接成功。

好友房是互信模式：房主设备会运行好友的战术源码。不要与不信任的陌生人交换邀请或运行其战术。

## 安全边界

当前 Bot 使用 Worker/VM 沙盒，足以支撑本地练习与互信好友房，但不是针对恶意不可信代码的强隔离。排位模式继续封存；在进程级或 WASM 隔离、账号、匹配与反作弊条件具备前不会恢复。

## 验证边界

自动化测试、类型检查、依赖审计、桌面构建、可移植候选、NSIS 生成与单机界面验收由发布门禁记录。两台真实 Windows 设备的局域网、异地邀请与应用重启恢复必须按仓库脚本分别记录；未执行的项目保持“待验收”，不会从浏览器双标签或本机回环推断为通过。
